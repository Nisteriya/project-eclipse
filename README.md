# Операции с файлами в файловой системе

## Открыть или создать файл  
Функция открывает файл в файловой системе. Если файл существует — открывает его, если отсутствует — создаёт и открывает.  
### - Параметры: имя файла (const char*)  
### - Возвращает: указатель на открытый файл (FILE*) или NULL при ошибке  

## Просмотреть файл  
Функция выводит содержимое файла из файловой системы.  
### - Параметры: имя файловой системы (const char*), имя файла внутри ФС (const char*)  
### - Возвращает: содержимое файла (char*), которое нужно освободить после использования, или NULL, если файл не найден  

## Удалить файл  
Функция удаляет файл из файловой системы.  
### - Параметры: имя файловой системы (const char*), имя файла (const char*)  
### - Возвращает: 1 при успешном удалении, 0 при ошибке или если файл не найден  

---

## Создать новый файл  
Создаёт новый файл в конце файловой системы с заданным содержимым.  
### - Параметры: имя ФС (const char*), имя файла (const char*), содержимое (const char*)  
### - Возвращает: 1 при успешном создании, 0 при ошибке  

## Изменить файл  
Изменяет содержимое существующего файла в файловой системе.  
### - Параметры: имя ФС (const char*), имя файла (const char*), новое содержимое (const char*)  
### - Возвращает: 1 при успешном изменении, 0 при ошибке или если файл не найден  

---

## Подключение библиотеки  
Файловая система реализована в библиотеке из двух файлов:  
### - filesystem.c (реализация функций)  
### - filesystem.h (заголовочный файл)  

Для использования функций нужно добавить оба файла в проект и в нужных исходниках подключить #include "filesystem.h".

---

# Примеры использования  
## - Создание файла:  
  создать test.txt "Привет мир" → Файл создан  
## - Просмотр содержимого:  
  просмотреть test.txt → Привет мир  
## - Изменение файла:  
  изменить test.txt "Новое содержимое" → Файл изменён  
## - Удаление файла:  
  удалить test.txt → Файл удалён
