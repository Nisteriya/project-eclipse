# **Project Eclipse**


## Операции с файлами в файловой системе

## filesystem.h
Заголовочный файл. Содержит объявлление функций: `-create_open_file` `-view_file` `-delete_file` `-add_file` `-modify_file.`    

## filesystem.c  
Функция **`create_open_file`**
Функция принимает имя файла. Если файл не существует, он создается. Если файл существует, он открывается. Функция возвращает открытый файловый дескриптор.

Функция **`view_file`**
Функция принимает имя файла и открывает его для чтения. Чтение начинается с начала файла. После каждой строки добавляется символ новой строки.

Функция **`delete_file`**
Функция принимает имя файла. Если файл существует, он удаляется. В противном случае возвращается сообщение об ошибке.

Функция **`add_file`**
Функция принимает имя нового файла. Если файл с таким именем уже существует, возвращается сообщение об ошибке. Затем функция принимает имя файла, чье содержимое будет записано в новый файл. ПРИМЕР:

`имя нового файла
имя существующего файла`
Функция modify_file
Функция принимает имя файла. Функция проверяет, существует ли файл. Если файл существует, его содержимое перезаписывается. В противном случае возвращается сообщение об ошибке.

## - Создание файла:  
  создать test.txt "Привет мир" → Файл создан  
## - Просмотр содержимого:  
  просмотреть test.txt → Привет мир  
## - Изменение файла:  
  изменить test.txt "Новое содержимое" → Файл изменён  
## - Удаление файла:  
  удалить test.txt → Файл удалён
